# Strategic Foresight Portfolio - Bancolombia

Este repositorio contiene el prototipo interactivo (Hoja de Vida / Presentación de Foresight) diseñado específicamente para el equipo de Inteligencia Estratégica de Bancolombia.

## Estructura del Repositorio
- `index.html`: Archivo principal que contiene la maquetación responsiva, el CSS (Dark Mode/Futurismo corporativo) y las animaciones JS.
- `README.md`: Este archivo.
- *(Nota: Asegúrate de colocar el archivo `HV_AnllyM_UpeguiV.pdf` en la raíz de este repositorio antes de desplegar, para que el enlace de descarga funcione correctamente).*

## Despliegue en Vercel
1. Inicia sesión en [Vercel](https://vercel.com/).
2. Conecta tu cuenta de GitHub y selecciona este repositorio.
3. Vercel detectará automáticamente que es un sitio estático (HTML/CSS).
4. Haz clic en **Deploy**.
5. ¡Listo! Tendrás un enlace en vivo para enviar por LinkedIn.
